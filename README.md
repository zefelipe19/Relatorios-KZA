# GERADOR DE RELATÓRIOS KZA
Esse é um gerador simples de relátorios para uma gráfica, o foco dele é ajudar na organização dos relátorios do mês.
## Objetivo
O objetivo é ser algo simples, que funcione inicialmente apenas na máquina de quem está usando. Todos os dados são salvos no localStorage do navegador.
